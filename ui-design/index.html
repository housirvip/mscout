一个窗口装下「搜索 → 改变 → 再搜索」的全过程

跨平台内存扫描与修改工具的桌面端界面原型。三个可交互页面覆盖主工作流与两个模态流程，全部按 1200×800 默认窗口、960px 最小宽度设计，含空状态、扫描中、结果收敛、冻结与置顶紧凑五类状态。

页面

主工作台是常驻界面，进程选择、内存查看器、右键菜单、Toast 与全部快捷键都在其中直接可用；指针扫描与 VM 扫描是从工作台唤起的模态流程，各自独立成页以便单独评审。

扫描工作台

四区常驻布局：工具栏 / 扫描控制 / 扫描结果 / 地址表。含进程选择弹窗、Hex 抽屉、两张表的右键菜单与置顶紧凑模式。

主界面进程弹窗Hex 查看器Toast快捷键

指针扫描

目标地址、最大深度（1–7）、最大偏移量三项输入，扫描中显示深度进度，结果以偏移链形式呈现，可多选加入地址表。

模态加载态偏移链多选

VM 扫描

两步流程：先按类型筛选宿主上检测到的虚拟机，再解析客户机内核并列出进程；含挂起虚拟机与「未检测到」两种失败路径。

两步流程空状态内核解析搜索过滤

视觉与密度

高密度不等于拥挤：分区靠 1px 细线、对齐靠等宽数字，阴影只用于浮层。

画布
Canvas White 主画布 + Soft Cloud 分区底色；所有区隔由 Hairline Gray 1px 完成，表格与面板一律不加阴影。
强调色
Rausch 珊瑚色全屏最多出现两次：主扫描按钮与匹配总数（小字改用 Deep Rausch 以满足 4.5:1）。冻结用语义绿，数值变动用加深的琥珀色。
Rausch Ink Black Soft Cloud 冻结 已变化
字体
UI 单字族 Airbnb Cereal VF（正文 500 重量）；地址、数值、十六进制与偏移链全部走等宽栈并开 tabular-nums，列对齐即结构。10px 大写标签统一 0.08em 字距。
密度
表格行高 27px，置顶紧凑模式压到 22px；控件高 34px、主 CTA 40px；数据组内间距 4–8px，区块之间 16–24px。

布局与状态

用户会不停切回游戏窗口，因此不做页面跳转，所有操作路径不超过两步。

骨架
顶部 56px 工具栏 · 左侧 300px 扫描控制常驻全高 · 中央扫描结果 · 底部 236px 地址表。
Hex 查看器
右侧 428px 浮层抽屉，从结果表或地址表右键唤起，不打断主流程；每行 16 字节 + ASCII，1 秒自动刷新。
百万级结果
每页 200 条窗口化渲染 + 页码跳转，只渲染当前页 DOM；总匹配数与页范围常驻显示。
置顶紧凑
工具栏折到 44px、行高降到 22px、按钮收成图标，便于与游戏窗口并排。

已覆盖的交互

  • 未附加空状态引导 → 进程搜索 → 附加就绪，差异条件在首次扫描后才解锁
  • 数据类型切换到字节数组时，值输入框改为十六进制模式串（含通配 ??）
  • 范围条件出双输入框，未知初始值 / 已改变等条件自动隐藏输入
  • 扫描进度条按区域数推进；再次扫描逐轮收敛并保留撤销栈
  • 地址表每 500ms 刷新，冻结行数值锁定，双击改值 / 双击重命名
  • Cheat Table 存取写入 localStorage，重开页面可恢复
  • 成功 / 错误 / 信息三类 Toast，右下角数秒后自动消失
